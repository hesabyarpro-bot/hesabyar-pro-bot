## نصب محلی

ساخت محیط مجازی:

python -m venv .venv

فعال‌سازی در Windows:

.venv\Scripts\activate

فعال‌سازی در Linux / Render:

source .venv/bin/activate

نصب:

pip install -r requirements.txt

---

## تنظیمات

فایل .env بساز:

BOT_TOKEN=توکن جدید ربات

ADMIN_ID=8806709666

CARD_NUMBER=شماره کارت

PLAN_MONTHLY=199000

PLAN_QUARTERLY=499000

DB_PATH=hesabyar.db

PORT=10000

---

## اجرای ربات

python -m app.main

---

## Render

Build Command:

pip install -r requirements.txt

Start Command:

python -m app.main

Health:

/health

## نکته مهم امنیتی

BOT_TOKEN نباید در GitHub قرار بگیرد.

توکن قبلی که قبلاً در اختیار دیگران قرار گرفته باید در BotFather با /revoke باطل شود.

توکن جدید فقط در Environment Variables مربوط به Render قرار بگیرد.

## وضعیت دیتابیس

SQLite برای MVP و تست مناسب است.

برای نسخه چندمشتری واقعی و تجاری بهتر است دیتابیس به PostgreSQL منتقل شود.

---

## وضعیت AI و OCR

ساختار اتصال AI و OCR در app/ai.py آماده شده است.

در این نسخه هیچ نتیجه ساختگی از AI تولید نمی‌شود.

اتصال واقعی OCR و AI باید پس از انتخاب سرویس AI انجام شود.
